# Confluence Page Templates

Use these templates when the user wants a polished page quickly. Adapt the structure to the team's norms instead of treating these as rigid forms.

## Meeting notes

```markdown
# [Meeting title]

## Summary
[1-3 sentence summary]

## Attendees
- ...

## Agenda
- ...

## Discussion
### Topic 1
- ...

## Decisions
- ...

## Action items
- [Owner] Action item - due date if known
```

## Rollback notes

- ...
