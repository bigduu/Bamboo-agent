---
name: skill-curator
description: Draft or revise a read-only project Workflow Skill from a user's explicit teaching in the Workflow authoring panel.
---

Use the Workflow authoring panel with an assigned Project. Describe the reusable
procedure, its inputs and expected result. Select an existing project definition
before teaching a revision. Review the proposed steps and changes, then save the
accepted revision through the host. Run the saved workflow separately.
