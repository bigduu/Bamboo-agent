# Operator-pinned remote broker activation

An explicit `subagents.remote_placements[].broker_peer` selects a scoped WSS broker using the existing endpoint, credential environment reference and CA file. Its closed parent/worker mailbox and role tuple is operator authority; mailboxes use strict lowercase spelling. The broker policy must allow the parent's Run/Steer/cancel and presence query for the selected worker role, and the worker's actual reply kinds. Missing credentials, invalid CA/role/route or duplicate strict role remain configured-unavailable. A legacy placement without `broker_peer` stays selected but fails closed; it never opens a direct parent-to-worker WebSocket or falls back to Local.

The actual Host/SubAgent consumer observes canonical durable Child birth, lineage, Project and ancestor metadata before connecting and again before Run. Strict links bind every selected current frame to the captured physical AgentRef and current correlation; typed events additionally match logical birth, activation and epoch. TLS actor clients keep durable and live actor frames ordered. Presence is connection observation, not HostRegistry or durable ownership authority.

The fixed parent subscription is single-flight for an ActorChildRunner's entire connection/Run/cleanup lifetime; a cancelled waiter sends no Run. Operators must assign a separate parent identity to each Host. Credentials are captured privately and never provisioned to the resident worker. Public placement is only a remote badge; browser config hides the entire strict topology and accepts only an exact current masked echo under the existing write lock. Operator configuration remains durable; ordinary legacy entries keep their API contract.

Source fixtures include actual WSS refusal/order tests and default-current-exe Host/SubAgent → real resident BambooRuntime → recorded provider, exact provider counts, cancellation, configured-unavailable cases, GET/save/cold route preservation, and cold same-Child cache identity. After Host disconnection, the controlled old worker completes and physically ACKs its old Run before explicit kill/wait and replacement. Stale parent frames cannot complete the new correlation. This does not prove worker-side Run anti-replay or automatic recovery.

Required-packet, named-profile and read-only Remote guards remain closed. HostRegistry, remote-owned activation, environment leases, stale-worker Run prevention, automatic resume, remote filesystem equivalence and the remainder of #1311/#925/#791 are outside this slice. Compilation/native acceptance is pending the shared verification lane.
