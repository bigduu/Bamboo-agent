# Builtin role package v1

The Skills package provides private `explorer`, `implementer` and independent adversarial `reviewer` definitions. Each prompt states its responsibility, bounded assignment, stop conditions and evidence expectations. Prompts are capped at 4 KiB (a caller may tighten the cap), use no model hint, and use only the existing Read, Glob, Bash, Edit and Write declarations. Explorer/reviewer allow Read/Glob and deny the other three; implementer lists the five tools and still requires the Host/Project/profile intersection. Declarations alone do not enforce or grant capabilities.

`ScopedNamedAgentCatalog::discover_with_builtins` explicitly opts into Project > Global > Builtin precedence. Safe public metadata includes source `builtin`, name, description and the SHA-256 revision of the exact versioned document. The old `discover` and Global-only catalog stay unchanged. Known higher-layer conflicts shadow the same builtin name; anonymous invalid or unavailable sources close selection, without falling back to a builtin. Static definitions share catalog candidate/text/publication budgets.

Definition bodies and tool policy remain private (no Serialize, metadata-only Debug). A retained identity selects only the exact immutable catalog observation, not current permission. Production SubAgent application, frozen Session identity/retry continuity, native read-only enforcement, safe Tool schema and authenticated catalog endpoint integration are verified at the later combined consumer delivery node. This package alone does not complete those #1315 acceptance criteria. Existing Plan and its hard read-only planner are unchanged.
